# Materiais de estudo

Organizados por fase. Quando o material é em inglês, está avisado — ler documentação em inglês é uma habilidade que você vai precisar de qualquer jeito, então vale como treino. Dica: leia primeiro sem tradutor, e só use quando travar.

## Antes de começar — API e HTTP (fase 1)

- [O que é uma API REST](https://www.redhat.com/pt-br/topics/api/what-is-a-rest-api) — Red Hat, português. O que é uma API REST e os princípios por trás.
- [Uma visão geral do HTTP](https://developer.mozilla.org/pt-BR/docs/Web/HTTP/Overview) — MDN, português. Como funciona o pedido e a resposta.
- [Métodos de requisição HTTP](https://developer.mozilla.org/pt-BR/docs/Web/HTTP/Methods) — MDN, português. GET, POST, PUT e DELETE: o CRUD na web.
- [Códigos de status HTTP](https://developer.mozilla.org/pt-BR/docs/Web/HTTP/Status) — MDN, português. Para consulta.

## Consumindo uma API em Python (fases 1, 2 e 6)

- [Requests: Quickstart](https://requests.readthedocs.io/en/latest/user/quickstart/) — inglês. GET com parâmetros, ler o JSON e checar o status.
- [python-dotenv](https://pypi.org/project/python-dotenv/) — inglês. Guardar chaves num arquivo `.env`.

## Banco de dados (fase 3)

- [SQLBolt](https://sqlbolt.com/) — inglês, interativo no navegador. Inclui inserir, alterar e apagar dados.
- [Módulo sqlite3](https://docs.python.org/pt-br/3/library/sqlite3.html) — documentação do Python, português. O tutorial no começo da página mostra criar tabela, inserir e consultar.

## Construindo o back-end (fases 4 e 5)

- [Tutorial do FastAPI](https://fastapi.tiangolo.com/pt/tutorial/) — português. Comece por "Primeiros passos", parâmetros de path, de consulta e corpo da requisição. (A tradução foi feita por IA com revisão humana.)
- [Testando com o FastAPI](https://fastapi.tiangolo.com/tutorial/testing/) — inglês. Como testar as rotas com pytest.
- [Tratamento de erros no FastAPI](https://fastapi.tiangolo.com/pt/tutorial/handling-errors/) — português. `HTTPException`.

## Testes

- [Documentação do pytest — Get started](https://docs.pytest.org/en/stable/getting-started.html) — inglês.
- [monkeypatch do pytest](https://docs.pytest.org/en/stable/how-to/monkeypatch.html) — inglês. A técnica usada em `test_fase2_tvmaze.py`.
